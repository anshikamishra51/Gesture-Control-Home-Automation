# Gesture Control Home Automation System

## About the Project
A smart home automation system that allows users to control home appliances using hand gestures.

## Technologies Used
- Python
- MediaPipe
- OpenCV
- Arduino UNO
- Serial Communication

## How It Works
1. Camera captures hand gestures.
2. MediaPipe detects hand landmarks.
3. Python processes the gestures.
4. Commands are sent to Arduino UNO.
5. Arduino controls LEDs and LCD display.

## Features
- Touchless appliance control
- Real-time gesture detection
- Low-cost implementation
- User-friendly operation
